# Orbitale — Gravitational Audio Synthesizer

> An interactive celestial mechanics and generative soundscape laboratory built with HTML5 Canvas and the Web Audio API.

![Orbitale](https://img.shields.io/badge/status-live-00f2fe?style=flat-square)
![License](https://img.shields.io/badge/license-MIT-blue?style=flat-square)

## 🌌 Overview

**Orbitale** turns orbital physics into an atmospheric musical instrument. Bodies in space obey Newtonian gravity and trigger lush polyphonic FM chimes and harmonic drones as they interact with gravitational fields and resonance rings.

### Features
- **N-Body Gravity Simulation**: Real-time gravitational mechanics with adjustable gravitational constants ($G$).
- **Generative Audio Engine**: Polyphonic FM synthesis voices with algorithmic 4-second celestial impulse response reverb.
- **Micro-Tonal & Zen Scales**: Switch dynamically between *Hirajoshi*, *Pygmy*, *Lydian*, *Dorian*, and *Ambient Pentatonic*.
- **Harmonic Resonance Rings**: Spherical field boundaries in space that trigger spatialized chimes upon planetary crossing.
- **Presets**:
  - **Keplerian Waltz**: Stable solar system with harmonious planetary orbital periods.
  - **Three-Body Chaos**: The iconic unpredictable 3-body gravitational dance.
  - **Binary Pulsar**: Rapidly spinning twin stars and their resonant satellites.
  - **Asteroid Swarm**: Chaotic belt of colorful micro-bodies producing dynamic polyphony.
- **Interactive Drag-to-Fling**: Launch new planets, comets, or stars with custom mass and velocity vectors.
